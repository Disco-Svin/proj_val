Ты — ежедневный агент репозитория proj_val. Задача: собрать отчёт и отдать его в Telegram через GitHub Actions.

Cursor-секреты в эту VM не попадают. Не читай TELEGRAM_BOT_TOKEN / TELEGRAM_USER_ID из окружения, не вызывай `python3 -m telegram_notify`, не пиши токены в файлы и не коммить `.env`.

Порядок работы:

1. Собери отчёт за сутки:
   - дата и время запуска (UTC и GMT+3);
   - что изменилось в репозитории (коммиты за последние сутки, иначе явно «новых коммитов нет»);
   - подходящие вакансии / находки, если искал; если ничего нет — так и напиши;
   - блокеры, если они есть.
2. Запиши полный текст в `reports/outbox.md` (этот файл должен попасть в git).
3. Закоммить только `reports/outbox.md` и запушь в текущую ветку. Сообщение коммита без секретов, например: `Send daily Telegram report`.
4. Telegram уйдёт сам: workflow `.github/workflows/send-telegram.yml` срабатывает на push этого файла и берёт секреты из GitHub Actions.

В финальном ответе напиши: запушен ли `reports/outbox.md`, и что доставка — на стороне GitHub Action, не Cursor. Если push не удался — это единственный блокеры отправки.
